Evidencia FIRMS Condicional · detección térmica histórica
Interpretación de detecciones FIRMS `type=0` significa *presumed vegetation fire*. Una detección térmica no confirma por sí sola un incendio individual; la ausencia de detecciones asociadas no demuestra ausencia de incendio.

La asociación de detecciones con el FWI de las 12:00 local del mismo día es histórica y descriptiva, no predictiva. Una detección anterior a las 12:00 puede quedar asociada a condiciones meteorológicas posteriores dentro de ese día.

Fuentes y limitaciones Método y procedencia
  • Límites geográficos: Instituto Geográfico Nacional de Argentina.
  • Meteorología histórica: Open-Meteo Historical API utilizando ERA5.
  • Detecciones térmicas: NASA FIRMS, VIIRS S-NPP.
  • Peligro meteorológico: Canadian Fire Weather Index System clásico.
  • Período principal 2021–2025; 2020 se usa para spin-up del FWI.
